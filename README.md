# OSHER Finance App

Aplicacao web financeira interna da OSHER para gestao de fundos, cotas, DRE, caixa, indicadores e relatorios gerenciais.

## Stack

- Next.js 14 com App Router
- TypeScript
- Tailwind CSS
- shadcn/ui + lucide-react
- Prisma ORM
- PostgreSQL
- Auth.js com e-mail e senha
- Recharts
- TanStack Table
- Zod

## Requisitos locais

- Windows 10/11
- VS Code
- Node.js LTS 20 ou superior
- npm 10 ou superior
- Docker Desktop, a partir da TASK 2

## Comandos iniciais

Abra o terminal na pasta raiz:

```powershell
cd "G:\Drives compartilhados\13. DATA ANALYSIS\12. Osher\osher-finance-app"
```

Instale as dependencias:

```powershell
npm install
```

Rode o servidor de desenvolvimento:

```powershell
npm run dev
```

Acesse:

```txt
http://localhost:3000
```
